# 📚 Manual de Buenas Prácticas para Trabajos Universitarios en Grupo

¡Bienvenidos al repositorio Control-de-versiones! Este proyecto tiene como objetivo fomentar la colaboración eficiente, la organización de tiempos, la correcta gestión de formatos y la aplicación de buenas prácticas en la elaboración de trabajos académicos grupales.

## Guía de Contribución y Flujo de Trabajo

Para mantener el control de versiones y garantizar revisiones de pares en *Control-de-versiones*, se sigue el siguiente flujo en GitHub:

1. *Creación de Ramas:* Trabajar siempre en ramas secundarias según la tarea asignada (ej. feature/gestion-tiempo o feature/normas-apa).
2. *Commits Claras:* Realizar commits frecuentes con mensajes descriptivos.
3. *Pull Requests (PR):* Al finalizar una sección, abrir un PR hacia la rama main y asignar a la otra compañera como *Reviewer*.
4. *Revisión de Pares:* La revisora debe comentar y aprobar el PR antes de hacer el *Merge*.
